# Turkish AI Benchmarks

Explore custom benchmarks evaluating AI models on Turkish-language tasks.

Select a benchmark to compare overall results and course accuracy, filter models
and courses, sort the results, and download the filtered tables. The interface
opens in Turkish and also supports English.
